## 🌿 &nbsp; Welcome to Tea House

**Tea House** is a front-end web project designed to showcase tea and ice cream through an inviting visual presentation. It brings together a warm tea-inspired theme and sweet treats in a simple website experience.

## 🛠️ &nbsp; Run It Locally

Want to explore the code on your own computer? Follow these quick steps.

**01 · Clone the repository**

```bash
git clone https://github.com/mahadihasandevx/Tea-House.git
```

**02 · Enter the project folder**

```bash
cd Tea-House
```

**03 · Open the page**

Open `index.html` in your web browser.

> If the project uses a different main HTML file, open that file instead.
